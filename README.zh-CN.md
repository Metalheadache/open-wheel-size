# open-wheel-size

独立维护的车辆轮圈与轮胎参考目录，用于研究、比较和工具开发，明确市场、车型年和前后轴范围。
本项目不是 Wheel-Size.com 的官方产品、镜像或 API 兼容克隆，也不获车辆制造商背书。

v1.0.1 发布完整的脱敏结构化研究目录：621 个平台/代际键、6,349 个市场/年份/版本配置、
11,771 个原厂套装、23,542 条前后轴记录、2,390 个来源及 732,391 条声明。
同时保留历史审核状态、补充事实、脱敏溯源记录、更正与已知问题。详见 [覆盖统计](COVERAGE.md)。

**所有未解决的权利标签原样保留；公开发布不代表法律许可或技术审核通过。**
所有者明确授权在这些标签未解决的情况下发布结构化事实。原来源材料再分发标签中，
2,355 个为 unknown，35 个为 notPermitted。文件复制限制不自动决定独立记录事实的权利，
但公开发布也不使未知权限变为已获许可。来源文档、凭据、个人信息及私人备注均未发布。

下载并解压 [Release](https://github.com/Metalheadache/open-wheel-size/releases) 后可离线使用 Python 3.9+：

```sh
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
python3 examples/query.py --market CN --limit 5
python3 scripts/release.py --output dist
```

主数据为 gzip 压缩的 UTF-8 JSON Lines；`data/index.json` 给出分片、数量及校验值。
旧版 1.0.0 便利包另含 CSV.gz，每个单元格使用 JSON 编码以保留 null、数字及布尔值。
原始完整主库保持私有；公开数据由字段白名单生成，不是另行手工维护的数据库。

尺寸使用数值及明确单位；未知值为 null，不得当作零。N/A 与冲突单独保留。
历史未知声明可能与后续已知声明共存，以 axles 表读取当前轮胎/轮圈值。
中文别名不代表中国市场配置；参考年份不能自动视为车型年；名义胎宽不代表实测胎宽。
原厂尺寸也不代表改装适配、间隙或安全性得到确认。
